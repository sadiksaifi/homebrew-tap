# Homebrew Tap for Sadik Saifi

This repository contains Homebrew formulae and casks for my projects.

## Installation

You can tap this repository to access all available formulae and casks:

```bash
brew tap sadiksaifi/tap
```

## Available Formulae

| Formula | Description | Installation | Link |
|:--- |:--- |:--- |:--- |
| **ai-git** | AI-powered git commit message generator | `brew install ai-git` | [ai-git](https://github.com/sadiksaifi/ai-git) |
| **mac-menu** | macOS-native GUI for fuzzy finding | `brew install mac-menu` | [mac-menu](https://github.com/sadiksaifi/mac-menu) |
| **mdp** | Markdown previewer with GitHub-styled rendering | `brew install mdp` | [mdopen](https://github.com/sadiksaifi/mdp) |

## Available Casks

| Cask | Description | Installation | Link |
|:--- |:--- |:--- |:--- |
| **spaceterm** | Native desktop terminal multiplexer | `brew install --cask sadiksaifi/tap/spaceterm` | [SpaceTerm](https://github.com/sadiksaifi/SpaceTerm) |
